# Deep Learning Practice Notebooks 📓

This repository contains Jupyter notebooks developed as part of my learning journey in the **"Data Science with Generative AI"** course by PW Skills. These notebooks demonstrate core machine learning concepts like model training, optimizers, and neural network implementation using TensorFlow and Keras.

---

## 🔍 Contents

### 🧠 `Optimizers.ipynb`
This notebook explores various optimization algorithms used in training deep learning models:
- **Optimizers covered:**
  - SGD (Stochastic Gradient Descent)
  - RMSprop
  - Adam
- **Key Concepts:**
  - How optimizers affect training speed and convergence
  - Loss and accuracy comparison between optimizers
- **Libraries Used:**
  - TensorFlow / Keras
  - Matplotlib

### 🛠️ `Practice.ipynb`
A hands-on notebook where:
- A simple neural network model is built using Keras
- The model is trained on sample image data
- Includes:
  - Data preprocessing
  - Model compilation and training
  - Performance evaluation
